# ArogyaNidhi

ArogyaNidhi is an Android healthcare application developed using Android Studio.  
The application is designed to help users access healthcare-related services in a simple and user-friendly way.

## Features

- User Registration and Login
- Doctor Information
- Appointment Booking
- Health Tips and Guidance
- Easy Navigation Interface
- Secure User Data Management

## Technologies Used

- Java / Kotlin
- Android Studio
- Firebase
- XML
- SQLite / Firebase Database

## Project Structure

```bash
ArogyaNidhi/
│── app/
│── gradle/
│── build.gradle
│── settings.gradle
│── AndroidManifest.xml
```

## Installation

1. Clone the repository

```bash
git clone https://github.com/gayathrims57/ArogyaNidhi.git
```

2. Open the project in Android Studio

3. Sync Gradle files

4. Run the application on:
   - Android Emulator
   - Physical Android Device

## Requirements

- Android Studio
- Android SDK
- Java/Kotlin Support
- Internet Connection
